# Prime Trilogy's Dolphin and Revolution SDK

Contains the decompiled source for the Dolphin SDK and Revolution SDK,
with support for the versions used by the Prime games.

Sourced from:
- https://github.com/doldecomp/dolsdk2004, for Echoes
- https://github.com/doldecomp/forecast and https://github.com/SMGCommunity/Petari, for Trilogy
- https://github.com/ivanno4317/dw4-gc, for the Apr 2003 libraries of the Echoes demo discs (CC0)
